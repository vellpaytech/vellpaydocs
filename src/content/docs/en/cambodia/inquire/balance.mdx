## Request parameters

This endpoint has no business request parameters. Send only the [Common request headers](/en/guides/request-headers/).

```json
{}
```

## Response parameters
| Field | Type | Required | Maximum length | Description |
|---|---|---|---:|---|
| `code` | int | Yes | - | Status code; a value other than 200 indicates an error |
| `data` | Object | Yes | - | Response body |
| `data.totalAmount` | String | Yes | 20 | Total amount |
| `data.frozenAmount` | String | Yes | 20 | Frozen amount |
| `data.availAmount` | String | Yes | 20 | Available balance |
| `msg` | String | No | - | Error message |
| `tid` | String | Yes | - | Trace ID |
