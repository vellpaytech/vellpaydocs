## Request parameters
| Field | Type | Required | Maximum length | Description |
|---|---|---|---:|---|
| `merchantOrderNo` | String | Yes | 32 | Merchant order number |
| `transactionAmount` | String | Yes | 20 | Pay-in amount, an integer or up to two decimal places |
| `paymentType` | String | No | 32 | [Payment method](#payment-methods) |
| `idType` | String | No | 32 | ID type: `CC`, `CE`, `NIT`, `PA` |
| `userIdCard` | String | No | 50 | ID number. `CC` and `CE` contain 6–10 digits; `NIT` contains 9 digits; `PA` contains 9 letters or digits. |
| `userName` | String | No | 64 | User name |
| `userPhone` | String | No | 10 | User mobile number, 10 digits; starts with `3`  |
| `userEmail` | String | No | 50 | User email |
| `expireTime` | String | No | - | Order expiration time (local time) |
| `description` | String | No | 100 | Description |
| `paymentCallbackUrl` | String | No | 200 | Pay-in callback URL |

## Request example

```json
{
  "merchantOrderNo": "CHECKOUT202609170001",
  "transactionAmount": "100.00",
  "paymentType": "PSE",
  "userPhone": "3000000000",
  "description": "Test checkout",
  "paymentCallbackUrl": "https://merchant.example/callback"
}
```

## Response parameters
| Field | Type | Required | Maximum length | Description |
|---|---|---|---:|---|
| `code` | int | Yes | - | Status code; a value other than 200 indicates an error |
| `data` | Object | Yes | - | Response body |
| `data.merchantOrderNo` | String | Yes | 32 | Merchant order number |
| `data.tradeNo` | String | Yes | 32 | Platform order number |
| `data.transactionAmount` | String | Yes | 20 | Pay-in amount |
| `data.status` | String | Yes | 20 | [Order status](/en/guides/order-status/) |
| `data.expireTime` | String | Yes | - | Expiration time (local time) |
| `data.paymentLink` | String | Yes | 24 | Payment link |
| `data.failMsg` | String | No | 200 | Order failure reason |
| `msg` | String | No | - | Error message |
| `tid` | String | Yes | - | Trace ID |
