## Request headers

[Common request headers](/en/guides/request-headers/#api-request-headers).

## Request parameters
| Field | Type | Required | Maximum length | Description |
|---|---|---|---:|---|
| `merchantOrderNo` | String | Yes | 32 | Merchant order number |

## Request example

```json
{
  "merchantOrderNo": "ORDER202609170001"
}
```

## Response parameters
| Field | Type | Required | Maximum length | Description |
|---|---|---|---:|---|
| `code` | int | Yes | - | Status code; a value other than 200 indicates an error |
| `data` | Object | Yes | - | Response body |
| `data.merchantOrderNo` | String | Yes | 24 | Merchant order number |
| `data.tradeNo` | String | Yes | 32 | Platform order number |
| `data.transactionAmount` | String | Yes | - | Pay-in amount |
| `data.status` | String | Yes | 24 | [Order status](/en/guides/order-status/) |
| `data.paymentType` | String | Yes | 24 | [Payment method](/en/argentina/payin/create/#payment-methods) |
| `data.failMsg` | String | No | 200 | Order failure reason |
| `data.paymentInfo` | String | No | 200 | Payment information |
| `data.serviceAmount` | String | No | 24 | Service fee |
| `data.paymentStatements` | List | No | - | Pay-in transaction list |
| `data.paymentStatements.paymentSingleOrderNo` | String | No | 32 | Pay-in transaction number |
| `data.paymentStatements.paymentAmount` | String | No | - | Actual received amount |
| `data.paymentStatements.paymentStatus` | String | No | 24 | [Order status](/en/guides/order-status/) |
| `data.paymentStatements.serviceAmount` | String | No | - | Service fee |
| `data.paymentStatements.serviceRate` | String | No | - | Service fee rate |
| `data.paymentStatements.immService` | String | No | - | Fixed fee |
| `data.paymentStatements.completeTime` | String | No | - | Order completion time (local time) |
| `msg` | String | No | - | Error message |
| `tid` | String | Yes | - | Trace ID |

## Order status

| Status | Description |
|---|---|
| `INIT` | Accepted |
| `PAYING` | Processing |
| `SUCCESS` | Completed |
| `FAIL` | Failed |
| `REFUND` | Refunded |
