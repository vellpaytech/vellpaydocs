<h2 id="channels">Payment channel values</h2>

`channel` must be combined with `paymentType` as shown in the table below, values are case-sensitive.

| `paymentType` | `channel` Allowed values | Whether `channel` is required |
|---|---|---|
| `PAYMENTLINK` | Not supported | No, must be left empty |
| `WALLET` | `DANA`, `LINKAJA`, `OVO` | No, when neededprovide |
| `VA` | `BRI`, `BNI`, `MANDIRI`, `PERMATA`, `CIMB`, `BCA` | No, when neededprovide |
| `QRIS` | Not supported | No, must be left empty |
| `QRIS_DIRECT` | Not supported | No, must be left empty |
| `VA_DIRECT` | `BRI`, `BNI`, `MANDIRI`, `PERMATA`, `CIMB`, `BCA` | **Yes** |

## Request parameters

| Field | Type | Required | Maximum length | Description |
|---|---|---|---:|---|
| `merchantOrderNo` | String | Yes | 32 | Merchant order number |
| `transactionAmount` | String | Yes | 20 | Pay-in amount; integers only |
| `paymentType` | String | Yes | 24 | [Payment method](#payment-methods) |
| `idType` | String | No | 32 | Optional ID type. This endpoint has no fixed enum; omit this field unless required by your business or payment channel. |
| `userIdCard` | String | No | 50 | ID number. No fixed format; omit this field unless required by your business or payment channel. |
| `userName` | String | Yes | 64 | User name |
| `userPhone` | String | Yes | 10–13 | User mobile number, 10–13 digits; starts with `08` |
| `userEmail` | String | Yes | 50 | User email |
| `bankCode` | String | No | 64 | Bank codes |
| `bankAccountNo` | String | No | 64 | Bank account number |
| `merchantName` | String | No | 64 | Merchant name |
| `description` | String | No | 100 | Description |
| `channel` | String | Conditionally required | 24 | [Payment channel](#channels); Required when `paymentType` is `VA_DIRECT`. For other payment methods, provide it only when specified above. |
| `expireTime` | String | No | - | Order expiration time (local time, format `yyyy-MM-dd HH:mm:ss`) |
| `paymentCallbackUrl` | String | No | 200 | Pay-in callback URL |
