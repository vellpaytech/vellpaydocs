## Request headers

[Common request headers](/en/guides/request-headers/#api-request-headers).

## Request parameters
| Field | Type | Required | Maximum length | Description |
|---|---|---|---:|---|
| `merchantOrderNo` | String | Yes | 32 | Merchant order number |

## Request example

```json
{
  "merchantOrderNo": "PAYOUT202609170001"
}
```

## Response parameters
| Field | Type | Required | Maximum length | Description |
|---|---|---|---:|---|
| `code` | int | Yes | - | Status code; a value other than 200 indicates an error |
| `data` | Object | Yes | - | Response body |
| `data.merchantOrderNo` | String | Yes | 32 | Merchant order number |
| `data.tradeNo` | String | Yes | 32 | Platform order number |
| `data.transactionAmount` | String | Yes | - | Payout amount |
| `data.payoutType` | String | Yes | 24 | [Payout method](/en/indonesia/payout/create/#payment-methods) |
| `data.status` | String | Yes | 20 | [Order status](/en/guides/order-status/) |
| `data.failMsg` | String | No | 24 | Order failure reason |
| `data.serviceAmount` | String | No | - | Service fee |
| `data.serviceRate` | String | No | - | Service fee rate |
| `data.immService` | String | No | - | Fixed fee |
| `data.completeTime` | String | No | - | Completion time (local time) |
| `msg` | String | No | - | Error message |
| `tid` | String | Yes | - | Trace ID |

## Order status

| Status | Description |
|---|---|
| `INIT` | Accepted |
| `PAYING` | Processing |
| `SUCCESS` | Completed |
| `FAIL` | Failed |
| `REFUND` | Refunded |
| `PART_REFUND` | Partially refunded |
