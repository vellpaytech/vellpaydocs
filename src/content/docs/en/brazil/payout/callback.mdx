---
title: Payout callback
description: VellPay sends Brazilian payout status and refund notifications to the merchant.
---

<p class="endpoint-lead">VellPay sends this callback to the payout callback URL supplied when the order was created or configured in the merchant console. You do not need to call the VellPay API.</p>

## Request parameters

| Field | Type | Required | Maximum length | Description |
|---|---|---|---:|---|
| `merchantOrderNo` | String | Yes | 32 | Merchant order number |
| `tradeNo` | String | Yes | 32 | Platform order number |
| `payoutAmount` | String | Yes | - | Payout amount, an integer or up to two decimal places |
| `payoutType` | String | Yes | 24 | [Payout method](../create/#payment-methods) |
| `payoutStatus` | String | Yes | 20 | [Order status](/en/guides/order-status/) |
| `failMsg` | String | No | 200 | Order failure reason |
| `serviceAmount` | String | No | - | Service fee |
| `completeTime` | String | Yes | - | Completion time (local time, format `yyyy-MM-dd HH:mm:ss`) |
| `refundNo` | String | No | 32 | Refund number; returned only for Brazilian payout refund notifications |
| `refundAmount` | String | No | - | Refund amount; returned only for Brazilian payout refund notifications |
| `refundTime` | String | No | - | Refund time; returned only for Brazilian payout refund notifications, format `yyyy-MM-dd HH:mm:ss` |

## Request example

```json
{
  "merchantOrderNo": "PAYOUT202609170001",
  "tradeNo": "TF2405220001BR0000508467743993",
  "payoutAmount": "100.00",
  "payoutType": "CPF",
  "payoutStatus": "REFUND",
  "serviceAmount": "1.00",
  "completeTime": "2026-09-17 15:30:00",
  "refundNo": "REFUND202609170001",
  "refundAmount": "100.00",
  "refundTime": "2026-09-17 16:00:00"
}
```

## Response parameters

| Field | Type | Required | Example | Description |
|---|---|---|---|---|
| `result` | String | Yes | `SUCCESS` | Return `SUCCESS` means the callback was received successfully; treat any other value as a failure |
| `msg` | String | No | `OK` | Processing result description |

## Response example

```json
{
  "result": "SUCCESS",
  "msg": "OK"
}
```



<div class="country-note">Only Brazilian payout callbacks include refund fields. Other countries do not return <code>refundNo</code>, <code>refundAmount</code> or <code>refundTime</code>.</div>
