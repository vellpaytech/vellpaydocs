<div class="country-note">No VellPay payout method is currently configured for Vietnam, so an executable sample request is not yet available. After activation, use the actual value confirmed by your VellPay representative for <code>payoutType</code> and bank code.</div>

<p class="endpoint-lead"></p>

<div class="method-path"><strong>POST</strong><code>/trade/payout/create</code></div>

## Request headers
[Common request headers](/en/guides/request-headers/).

<h2 id="payment-methods">Payment method values</h2>

No payment method is currently configured.

## Request parameters
| Field | Type | Required | Maximum length | Description |
|---|---|---|---:|---|
| `merchantOrderNo` | String | Yes | 32 | Merchant order number |
| `transactionAmount` | String | Yes | 20 | Payout amount, an integer or up to two decimal places |
| `payoutType` | String | Yes | 20 | [Payout method](#payment-methods) |
| `idType` | String | No | 32 | Optional ID type. This endpoint has no fixed enum; omit this field unless required by your business or payment channel. |
| `userIdCard` | String | No | 50 | ID number. No fixed format; omit this field unless required by your business or payment channel. |
| `userName` | String | No | 64 | User name |
| `userPhone` | String | No | 10 | User mobile number, 10 digits; starts with `03`, `05`, `07`, `08` or `09`  |
| `userEmail` | String | No | 50 | User email |
| `bankCode` | String | No | 20 | [Bank codes](../banks/) |
| `bankName` | String | No | - | Bank name, see [Bank code description](../banks/) |
| `bankAccountNo` | String | Yes | 50 | Beneficiary account |
| `description` | String | No | 100 | Description |
| `payoutCallbackUrl` | String | No | 200 | Payout callback URL |



## Request example

The following example shows the field structure. Before submitting, replace `payoutType` and the bank details with values confirmed by your VellPay representative.

```json
{
  "merchantOrderNo": "PAYOUT202609170001",
  "transactionAmount": "100000.00",
  "payoutType": "PAYOUT_TYPE",
  "idType": "NATIONAL_ID",
  "userIdCard": "012345678901",
  "userName": "TEST USER",
  "userPhone": "0912345678",
  "userEmail": "user@example.com",
  "bankCode": "970436",
  "bankName": "Vietcombank",
  "bankAccountNo": "1234567890",
  "description": "Payout order",
  "payoutCallbackUrl": "https://merchant.example/payout-callback"
}
```

## Response parameters
| Field | Type | Required | Maximum length | Description |
|---|---|---|---:|---|
| `code` | int | Yes | - | Status code; a value other than 200 indicates an error |
| `data` | Object | Yes | - | Response body |
| `data.merchantOrderNo` | String | Yes | 32 | Merchant order number |
| `data.tradeNo` | String | Yes | 32 | Platform order number |
| `data.transactionAmount` | String | Yes | - | Payout amount |
| `data.status` | String | Yes | 24 | [Order status](/en/guides/order-status/) |
| `data.payoutType` | String | Yes | 24 | [Payout method](#payment-methods) |
| `msg` | String | No | - | Error message |
| `tid` | String | Yes | - | Trace ID |
