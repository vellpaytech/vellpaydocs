## 响应参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.totalAmount` | String | 是 | 20 | 总金额 |
| `data.frozenAmount` | String | 是 | 20 | 冻结金额 |
| `data.availAmount` | String | 是 | 20 | 当前可用余额 |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |

## 响应示例

```json
{
  "code": 200,
  "data": {
    "totalAmount": "10000.00",
    "frozenAmount": "100.00",
    "availAmount": "9900.00"
  },
  "msg": "success",
  "tid": "747bbf80261844ed85b809212aab0d81"
}
```
