## 请求头
[公共请求头](/zh/guides/request-headers/)。

<h2 id="payment-methods">支付方式参数</h2>

| `payoutType` |
|---|
| `BANK_TRANSFER` |

## 请求参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `transactionAmount` | String | 是 | 20 | 付款金额，整数（保留 2 位小数） |
| `payoutType` | String | 是 | 20 | [代付方式](#payment-methods) |
| `idType` | String | 否 | 32 | 可选的证件类型；当前接口没有固定枚举，无业务或渠道要求时可不传 |
| `userIdCard` | String | 否 | 50 | 证件号码。无固定格式，无业务或渠道要求时可不传 |
| `userName` | String | 是 | 64 | 用户姓名 |
| `userPhone` | String | 是 | 20 | 用户手机号 |
| `userEmail` | String | 是 | 50 | 用户邮箱 |
| `bankCode` | String | 是 | 20 | [银行编码](../banks/) |
| `bankName` | String | 是 | 50 | [银行名称](../banks/) |
| `bankAccountNo` | String | 是 | 50 | 收款账户 |
| `description` | String | 否 | 100 | 说明 |
| `payoutCallbackUrl` | String | 否 | 200 | 代付回调地址 |



## 请求示例

```json
{
  "merchantOrderNo": "PAYOUT202609170001",
  "transactionAmount": "100.00",
  "payoutType": "BANK_TRANSFER",
  "userName": "TEST USER",
  "userPhone": "081234567890",
  "userEmail": "user@example.com",
  "bankCode": "0007",
  "bankName": "Bank BCA",
  "bankAccountNo": "1234567890"
}
```

## 响应参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `data.tradeNo` | String | 是 | 32 | 平台单号 |
| `data.transactionAmount` | String | 是 | - | 付款金额 |
| `data.status` | String | 是 | 24 | [订单状态](/zh/guides/order-status/) |
| `data.payoutType` | String | 是 | 24 | [代付方式](#payment-methods) |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |

## 响应示例

```json
  "code": 200,
  "data": {

  },
  "msg": "success",
  "tid": "747bbf80261844ed85b809212aab0d81"
}
```
