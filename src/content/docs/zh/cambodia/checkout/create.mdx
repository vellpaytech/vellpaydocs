| `paymentType` |

## 请求参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `transactionAmount` | String | 是 | 20 | 收款金额，整数（保留 2 位小数） |
| `paymentType` | String | 否 | 32 | [支付方式](#payment-methods) |
| `idType` | String | 否 | 50 | 身份识别类型：`NONE_KYC` 或 `KYC` |
| `userIdCard` | String | 否 | 32 | 平台身份识别码，最长 32 位 |
| `userName` | String | 否 | 64 | 用户姓名 |
| `userPhone` | String | 否 | 20 | 用户手机号 |
| `userEmail` | String | 否 | 50 | 用户邮箱 |
| `expireTime` | String | 否 | - | 订单过期时间（国家当地时间） |
| `paymentCallbackUrl` | String | 否 | 200 | 代收回调地址 |

## 请求示例

```json
{
  "merchantOrderNo": "CHECKOUT202609170001",
  "transactionAmount": "100.00",
  "paymentType": "KHQR",
  "paymentCallbackUrl": "https://merchant.example/callback"
}
```

## 响应参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `data.tradeNo` | String | 是 | 32 | 平台单号 |
| `data.transactionAmount` | String | 是 | 20 | 收款金额 |
| `data.status` | String | 是 | 20 | [订单状态](/zh/guides/order-status/) |
| `data.expireTime` | String | 是 | - | 过期时间（国家当地时间） |
| `data.paymentLink` | String | 是 | 24 | 支付链接 |
| `data.failMsg` | String | 否 | 200 | 订单失败原因 |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |
