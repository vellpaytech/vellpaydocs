---
title: 柬埔寨 KYC 回调
description: KYC 认证状态发生变化时，VellPay 向 kycCallbackUrl 推送通知。
---

<p class="endpoint-lead">该回调由 VellPay 主动发送至创建 KYC 时传入的 <code>kycCallbackUrl</code>，不需要调用 VellPay API。</p>

## 请求参数

| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `userPhone` | String | 是 | 8～9 | 用户手机号码，8～9 位数字 |
| `authenticationStatus` | String | 是 | 32 | [KYC 状态](/zh/guides/order-status/#kyc-状态) |

## 请求示例

```json
{
  "userPhone": "12345678",
  "authenticationStatus": "APPROVED"
}
```

## 响应参数

| 字段 | 类型 | 必填 | 示例值 | 说明 |
|---|---|---|---|---|
| `result` | String | 是 | `SUCCESS` | `SUCCESS` / `FAIL`；`SUCCESS` 表示商户成功接收通知 |
| `msg` | String | 否 | `OK` | 错误原因 |

## 响应示例

```json
{
  "result": "SUCCESS",
  "msg": "OK"
}
```
