<div class="method-path"><strong>POST</strong><code>/trade/kyc/create</code></div>

## 请求参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `userIdCard` | String | 是 | 50 | 证件号码（商户侧用户标识）。传 1～50 位字母或数字；同一用户在 KYC、代收和代付接口中必须保持一致 |
| `userName` | String | 是 | 64 | 用户姓名 |
| `userPhone` | String | 是 | 8～9 | 柬埔寨本地手机号，不含国家区号 |
| `kycCallbackUrl` | String | 是 | 200 | KYC 状态回调地址 |

## 请求示例

```json
{
  "userIdCard": "K12345678",
  "userName": "TEST USER",
  "userPhone": "12345678",
  "kycCallbackUrl": "https://merchant.example/kyc-callback"
}
```

## 响应参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.userPhone` | String | 是 | 8～9 | 用户手机号 |
| `data.authenticationStatus` | String | 是 | 32 | [KYC 状态](/zh/guides/order-status/#kyc-状态) |
| `data.authenticationUrl` | String | 是 | 20 | 认证地址 |
| `data.failMsg` | String | 否 | 20 | 失败原因 |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |

## 响应示例

```json
{
  "code": 200,
  "data": {
    "userPhone": "12345678",
    "authenticationStatus": "PENDING",
    "authenticationUrl": "https://kyc.example/verify"
  },
  "msg": "success",
  "tid": "747bbf80261844ed85b809212aab0d81"
}
```
