<div class="method-path"><strong>POST</strong><code>/trade/kyc/query</code></div>

## 请求头

[公共请求头](/zh/guides/request-headers/#api-request-headers)。

## 请求参数
| 字段 | 类型 | 必填 | 长度 | 说明 |
|---|---|---|---:|---|
| `userPhone` | String | 是 | 8～9 | 用户手机号码，8～9 位数字 |

## 请求示例

```json
{
  "userPhone": "12345678"
}
```

## 响应参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.authenticationStatus` | String | 是 | 32 | [KYC 状态](/zh/guides/order-status/#kyc-状态) |
| `data.failMsg` | String | 否 | 20 | 失败原因 |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |

## 响应示例

```json
{
  "code": 200,
  "data": {
    "authenticationStatus": "APPROVED",
    "failMsg": null
  },
  "msg": "success",
  "tid": "747bbf80261844ed85b809212aab0d81"
}
```
