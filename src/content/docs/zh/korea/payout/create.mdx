## 请求参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `transactionAmount` | String | 是 | 20 | 付款金额，整数（保留 2 位小数） |
| `payoutType` | String | 是 | 20 | [代付方式](#payment-methods) |
| `idType` | String | 是 | 50 | 收款人类型：`RRN`（个人）或 `CO`（企业） |
| `userIdCard` | String | 否 | 50 | 证件号码。个人 `RRN` 为 13 位数字；企业 `CO` 为 10 位企业登记号；当前接口不强制传入 |
| `userName` | String | 是 | 64 | 用户姓名 |
| `userPhone` | String | 是 | 11 | 用户手机号码，11 位数字，以 `010` 开头 |
| `userEmail` | String | 否 | 50 | 用户邮箱 |
| `userDepositCount` | Integer | 否 | - | 用户在商户侧的历史成功出账总笔数，非负整数，例如 `0`、`1`、`5`。详见[用户历史交易信息](#merchant-history) |
| `userFirstDepositTime` | Long | 否 | - | 用户在商户侧首次成功出账的时间，13 位毫秒级时间戳，例如 `1732929200000`。详见[用户历史交易信息](#merchant-history) |
| `bankCode` | String | 是 | 20 | [银行编码](/zh/korea/bank/) |
| `bankName` | String | 是 | 50 | [银行名称](/zh/korea/bank/) |
| `bankAccountNo` | String | 是 | 50 | 收款账户 |
| `description` | String | 否 | 100 | 说明 |
| `payoutCallbackUrl` | String | 否 | 200 | 代付回调地址 |



<h3 id="merchant-history">用户历史交易信息</h3>

`userDepositCount`：

1. 统计口径：仅统计该用户在商户侧已出账成功（终态成功）的出账订单总笔数，不含待支付、已取消、失败或退款/冲正订单。
2. 边界说明：`0` 或不传代表该用户在商户侧暂无历史成功出账记录（或尚未完成首次出账）。
3. 使用说明：作为出款风控评估与路由分流的参考因子之一，平台将结合自身历史交易记录综合判定。

`userFirstDepositTime`：

1. 统计口径：取该用户在商户侧第一笔已出账成功订单的完成/入账时间，非用户注册时间或当前请求时间。
2. 边界说明：当 `userDepositCount` 为 `0` 或无历史成功出账记录时，本字段无需传递。时间戳须为合法的 13 位毫秒级时间戳，且不晚于当前请求时间；若数值异常或与出账次数逻辑冲突，平台将不采纳该参考值。
3. 使用说明：作为出款风控评估与路由分流的参考因子之一，平台将结合自身历史交易记录综合判定。

## 响应参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `data.tradeNo` | String | 是 | 32 | 平台单号 |
| `data.transactionAmount` | String | 是 | - | 付款金额 |
| `data.status` | String | 是 | 24 | [订单状态](/zh/guides/order-status/) |
| `data.payoutType` | String | 是 | 24 | [代付方式](#payment-methods) |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |
