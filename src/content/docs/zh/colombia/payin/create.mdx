## 请求参数

| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `transactionAmount` | String | 是 | 20 | 收款金额 |
| `paymentType` | String | 是 | 24 | [支付方式](#payment-methods) |
| `idType` | String | 条件必填 | 32 | `paymentType` 为 `PSE` 或 `NEQUI_PSE` 时必填；可选值：`CC`、`CE`、`NIT`、`PA` |
| `userIdCard` | String | 条件必填 | 50 | 证件号码。`paymentType` 为 `PSE` 或 `NEQUI_PSE` 时必填；`CC`、`CE` 为 6～10 位数字；`NIT` 为 9 位数字；`PA` 为 9 位字母或数字 |
| `userName` | String | 是 | 64 | 用户姓名 |
| `userPhone` | String | 是 | 10 | 用户手机号码，10 位数字，以 `3` 开头 |
| `userEmail` | String | 是 | 50 | 用户邮箱 |
| `bankCode` | String | 否 | 64 | 银行编码 |
| `bankAccountNo` | String | 否 | 64 | 银行账户号 |
| `merchantName` | String | 否 | 64 | 商户名称 |
| `description` | String | 否 | 100 | 说明 |
| `expireTime` | String | 否 | - | 订单过期时间（国家当地时间，格式 `yyyy-MM-dd HH:mm:ss`） |
| `paymentCallbackUrl` | String | 否 | 200 | 代收回调地址 |

## 请求示例

```json
{
  "merchantOrderNo": "ORDER202609170001",
  "transactionAmount": "100.00",
  "paymentType": "PSE",
  "idType": "CC",
  "userIdCard": "1234567890",
  "userName": "TEST USER",
  "userPhone": "3001234567",
  "userEmail": "user@example.com",
  "paymentCallbackUrl": "https://merchant.example/callback"
}
```

## 响应参数

| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.merchantOrderNo` | String | 是 | 24 | 商户订单号 |
| `data.tradeNo` | String | 是 | 32 | 平台单号 |
| `data.transactionAmount` | String | 是 | - | 收款金额，整数或保留 2 位小数 |
| `data.status` | String | 是 | 24 | [订单状态](/zh/guides/order-status/) |
| `data.paymentType` | String | 是 | 24 | [支付方式](#payment-methods) |
| `data.failMsg` | String | 否 | 200 | 订单失败原因 |
| `data.paymentInfo` | String | 否 | 200 | 支付信息 |
| `data.additional` | Object | 否 | - | 附加信息 |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |
