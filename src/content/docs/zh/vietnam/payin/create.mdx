<div class="country-note">越南当前没有已配置的 VellPay 代收方式，因此暂不提供模拟请求。开通后请使用商务确认的实际 <code>paymentType</code>。</div>



<div class="method-path"><strong>POST</strong><code>/trade/payment/create</code></div>

## 请求头
[公共请求头](/zh/guides/request-headers/)。

<h2 id="payment-methods">支付方式参数</h2>

当前暂无已配置的支付方式。

## 请求参数

| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `transactionAmount` | String | 是 | 20 | 收款金额 |
| `paymentType` | String | 是 | 24 | [支付方式](#payment-methods) |
| `idType` | String | 否 | 32 | 可选的证件类型；当前接口没有固定枚举，无业务或渠道要求时可不传 |
| `userIdCard` | String | 否 | 50 | 证件号码。无固定格式，无业务或渠道要求时可不传 |
| `userName` | String | 否 | 64 | 用户姓名 |
| `userPhone` | String | 否 | 10 | 用户手机号码，10 位数字，以 `03`、`05`、`07`、`08` 或 `09` 开头 |
| `userEmail` | String | 否 | 50 | 用户邮箱 |
| `bankCode` | String | 否 | 64 | 银行编码 |
| `bankAccountNo` | String | 否 | 64 | 银行账户号 |
| `merchantName` | String | 否 | 64 | 商户名称 |
| `description` | String | 否 | 100 | 说明 |
| `expireTime` | String | 否 | - | 订单过期时间（国家当地时间，格式 `yyyy-MM-dd HH:mm:ss`） |
| `paymentCallbackUrl` | String | 否 | 200 | 代收回调地址 |

## 请求示例

以下示例用于展示字段结构；提交前请将 `paymentType` 替换为商务确认的实际值。

```json
{
  "merchantOrderNo": "ORDER202609170001",
  "transactionAmount": "100000.00",
  "paymentType": "PAYMENT_TYPE",
  "idType": "NATIONAL_ID",
  "userIdCard": "012345678901",
  "userName": "TEST USER",
  "userPhone": "0912345678",
  "userEmail": "user@example.com",
  "bankCode": "970436",
  "bankAccountNo": "1234567890",
  "merchantName": "TEST MERCHANT",
  "description": "Payment order",
  "expireTime": "2026-09-21 18:00:00",
  "paymentCallbackUrl": "https://merchant.example/callback"
}
```

## 响应参数

| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.merchantOrderNo` | String | 是 | 24 | 商户订单号 |
| `data.tradeNo` | String | 是 | 32 | 平台单号 |
| `data.transactionAmount` | String | 是 | - | 收款金额，整数或保留 2 位小数 |
| `data.status` | String | 是 | 24 | [订单状态](/zh/guides/order-status/) |
| `data.paymentType` | String | 是 | 24 | [支付方式](#payment-methods) |
| `data.failMsg` | String | 否 | 200 | 订单失败原因 |
| `data.paymentInfo` | String | 否 | 200 | 支付信息 |
| `data.additional` | Object | 否 | - | 附加信息 |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |
