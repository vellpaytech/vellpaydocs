<div class="country-note">越南当前没有已配置的 VellPay 代付方式，因此暂不提供模拟请求。开通后请使用商务确认的实际 <code>payoutType</code> 和银行编码。</div>

<p class="endpoint-lead"></p>

<div class="method-path"><strong>POST</strong><code>/trade/payout/create</code></div>

## 请求头
[公共请求头](/zh/guides/request-headers/)。

<h2 id="payment-methods">支付方式参数</h2>

当前暂无已配置的支付方式。

## 请求参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `transactionAmount` | String | 是 | 20 | 付款金额，整数（保留 2 位小数） |
| `payoutType` | String | 是 | 20 | [代付方式](#payment-methods) |
| `idType` | String | 否 | 32 | 可选的证件类型；当前接口没有固定枚举，无业务或渠道要求时可不传 |
| `userIdCard` | String | 否 | 50 | 证件号码。无固定格式，无业务或渠道要求时可不传 |
| `userName` | String | 否 | 64 | 用户姓名 |
| `userPhone` | String | 否 | 10 | 用户手机号码，10 位数字，以 `03`、`05`、`07`、`08` 或 `09` 开头 |
| `userEmail` | String | 否 | 50 | 用户邮箱 |
| `bankCode` | String | 否 | 20 | [银行编码](../banks/) |
| `bankName` | String | 否 | - | 银行名称，参见[银行编码说明](../banks/) |
| `bankAccountNo` | String | 是 | 50 | 收款账户 |
| `description` | String | 否 | 100 | 说明 |
| `payoutCallbackUrl` | String | 否 | 200 | 代付回调地址 |



## 请求示例

以下示例用于展示字段结构；提交前请将 `payoutType` 和银行信息替换为商务确认的实际值。

```json
{
  "merchantOrderNo": "PAYOUT202609170001",
  "transactionAmount": "100000.00",
  "payoutType": "PAYOUT_TYPE",
  "idType": "NATIONAL_ID",
  "userIdCard": "012345678901",
  "userName": "TEST USER",
  "userPhone": "0912345678",
  "userEmail": "user@example.com",
  "bankCode": "970436",
  "bankName": "Vietcombank",
  "bankAccountNo": "1234567890",
  "description": "Payout order",
  "payoutCallbackUrl": "https://merchant.example/payout-callback"
}
```

## 响应参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `data.tradeNo` | String | 是 | 32 | 平台单号 |
| `data.transactionAmount` | String | 是 | - | 付款金额 |
| `data.status` | String | 是 | 24 | [订单状态](/zh/guides/order-status/) |
| `data.payoutType` | String | 是 | 24 | [代付方式](#payment-methods) |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |

  },
