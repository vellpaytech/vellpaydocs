## 请求参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `transactionAmount` | String | 是 | 20 | 代付金额（VND），仅支持整数 |
| `payoutType` | String | 是 | 20 | [代付方式](#payment-methods) |
| `idType` | String | 是 | 32 | 证件类型：`BRBANK` |
| `userIdCard` | String | 是 | 32 | 证件号码 |
| `userName` | String | 是 | 255 | 用户姓名：传用户的真实姓与名 |
| `userPhone` | String | 是 | 50 | 电话号码，以 `0` 开头的 10 位数字 |
| `userEmail` | String | 是 | 50 | 收款人邮箱，传用户的真实邮箱 |
| `bankCode` | String | 是 | 50 | 银行编码，参考[银行列表](/zh/vietnam/bank/) |
| `bankName` | String | 是 | 50 | 银行名称，参考[银行列表](/zh/vietnam/bank/) |
| `bankAccountNo` | String | 是 | 32 | 收款账号：传输用户真实收款账号信息 |
| `description` | String | 否 | 100 | 说明 |
| `payoutCallbackUrl` | String | 否 | 200 | 代付回调地址 |



## 请求示例

以下示例用于展示字段结构；提交前请将 `payoutType` 和银行信息替换为商务确认的实际值。

```json
{
  "merchantOrderNo": "PAYOUT202609170001",
  "transactionAmount": "100000",
  "payoutType": "BANK",
  "idType": "BRBANK",
  "userIdCard": "012345678901",
  "userName": "Nguyen Van A",
  "userPhone": "0912345678",
  "userEmail": "user@example.com",
  "bankCode": "1043",
  "bankName": "VCB",
  "bankAccountNo": "1234567890",
  "description": "Payout order",
  "payoutCallbackUrl": "https://merchant.example/payout-callback"
}
```

## 响应参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `data.tradeNo` | String | 是 | 32 | 平台单号 |
| `data.transactionAmount` | String | 是 | - | 代付金额（VND），仅支持整数 |
| `data.status` | String | 是 | 24 | [订单状态](/zh/guides/order-status/)，创建时为 `PAYING`（支付中）或 `FAIL`（已失败） |
| `data.payoutType` | String | 是 | 24 | [代付方式](#payment-methods) |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |
