<div class="method-path"><strong>POST</strong><code>/trade/suspenseAccount/reorder</code></div>

## 请求参数
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `bankId` | String | 是 | 银行凭证 ID |
| `merchantOrderNo` | String | 是 | 商户订单号 |

## 请求示例

```json
{
  "bankId": "BANK_ID",
  "merchantOrderNo": "ORDER202609170001"
}
```

## 响应参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.amount` | String | 是 | - | 补单金额 |
| `data.tradeNo` | String | 是 | - | 平台订单号 |
| `data.bankId` | String | 是 | - | 银行凭证 ID |
| `data.merchantOrderNo` | String | 是 | - | 商户订单号 |
| `data.callbackTime` | String | 否 | - | 回调时间（阿根廷当地时间） |
| `data.status` | String | 是 | - | 补单结果状态 |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |

## 响应示例

```json
{
  "code": 200,
  "data": {
    "amount": "100.00",
    "tradeNo": "VS2608270002AR0000000000040059",
    "bankId": "BANK_ID",
    "merchantOrderNo": "ORDER202609170001",
    "callbackTime": "2026-09-17 12:00:00",
    "status": "SUCCESS"
  },
  "msg": "success",
  "tid": "747bbf80261844ed85b809212aab0d81"
}
```
