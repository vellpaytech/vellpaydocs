<div class="method-path"><strong>POST</strong><code>/trade/query/suspenseAccount/order</code></div>

## 请求参数
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `bankId` | String | 是 | 银行凭证 ID |

## 请求示例

```json
{
  "bankId": "BANK_ID"
}
```

## 响应参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.suspenseAmount` | String | 是 | - | 悬账金额 |
| `data.theoreticalAmount` | String | 是 | - | 理论到账金额 |
| `data.suspenseStatus` | String | 是 | - | 悬账状态 |
| `data.suspenseIdCardNumber` | String | 否 | - | 悬账用户证件号 |
| `data.suspenseRealName` | String | 否 | - | 悬账用户姓名 |
| `data.suspenseCallbackTime` | String | 否 | - | 悬账回调时间（阿根廷当地时间） |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |

## 响应示例

```json
{
  "code": 200,
  "data": {
    "suspenseAmount": "100.00",
    "theoreticalAmount": "100.00",
    "suspenseStatus": "PENDING",
    "suspenseIdCardNumber": "ID_NUMBER",
    "suspenseRealName": "TEST USER",
    "suspenseCallbackTime": "2026-09-17 12:00:00"
  },
  "msg": "success",
  "tid": "747bbf80261844ed85b809212aab0d81"
}
```
