## 请求头

[公共请求头](/zh/guides/request-headers/#api-request-headers)。

## 请求参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `merchantOrderNo` | String | 是 | 32 | 商户订单号 |

## 请求示例

```json
{
  "merchantOrderNo": "PAYOUT202609170001"
}
```

## 响应参数
| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `code` | int | 是 | - | 状态码，非 200 代表异常 |
| `data` | Object | 是 | - | 响应体 |
| `data.merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `data.tradeNo` | String | 是 | 32 | 平台单号 |
| `data.transactionAmount` | String | 是 | - | 付款金额 |
| `data.payoutType` | String | 是 | 24 | [代付方式](/zh/brazil/payout/create/#payment-methods) |
| `data.status` | String | 是 | 20 | [订单状态](/zh/guides/order-status/) |
| `data.failMsg` | String | 否 | 24 | 订单失败原因 |
| `data.serviceAmount` | String | 否 | - | 服务费用 |
| `data.serviceRate` | String | 否 | - | 服务费率 |
| `data.immService` | String | 否 | - | 固收 |
| `data.completeTime` | String | 否 | - | 完成时间（国家当地时间） |
| `data.totalRefundAmount` | String | 否 | - | 退款总金额 |
| `data.refundDetails` | Array | 否 | - | 退款明细集合 |
| `data.refundDetails.refundNo` | String | 否 | 32 | 退款单号 |
| `data.refundDetails.refundAmount` | String | 否 | - | 退款金额 |
| `data.refundDetails.refundTime` | String | 否 | - | 退款时间（国家当地时间，格式 `yyyy-MM-dd HH:mm:ss`） |
| `msg` | String | 否 | - | 异常信息 |
| `tid` | String | 是 | - | traceId |

## 订单状态

| 状态 | 说明 |
|---|---|
| `INIT` | 受理中 |
| `PAYING` | 交易中 |
| `SUCCESS` | 已完成 |
| `FAIL` | 已失败 |
| `REFUND` | 已退款 |
| `PART_REFUND` | 部分退款 |
