---
title: 代付回调
description: VellPay 向商户推送巴西代付订单状态及退款通知。
---

<p class="endpoint-lead">该回调由 VellPay 主动发送至创建订单时传入或商户后台配置的代付回调地址，不需要调用 VellPay API。</p>

## 请求参数

| 字段 | 类型 | 必填 | 最大长度 | 说明 |
|---|---|---|---:|---|
| `merchantOrderNo` | String | 是 | 32 | 商户订单号 |
| `tradeNo` | String | 是 | 32 | 平台单号 |
| `payoutAmount` | String | 是 | - | 付款金额，整数或保留 2 位小数 |
| `payoutType` | String | 是 | 24 | [代付方式](../create/#payment-methods) |
| `payoutStatus` | String | 是 | 20 | [订单状态](/zh/guides/order-status/) |
| `failMsg` | String | 否 | 200 | 订单失败原因 |
| `serviceAmount` | String | 否 | - | 服务费用 |
| `completeTime` | String | 是 | - | 完成时间（国家当地时间，格式 `yyyy-MM-dd HH:mm:ss`） |
| `refundNo` | String | 否 | 32 | 退款单号；仅巴西代付退款通知返回 |
| `refundAmount` | String | 否 | - | 退款金额；仅巴西代付退款通知返回 |
| `refundTime` | String | 否 | - | 退款时间；仅巴西代付退款通知返回，格式 `yyyy-MM-dd HH:mm:ss` |

## 请求示例

```json
{
  "merchantOrderNo": "PAYOUT202609170001",
  "tradeNo": "TF2405220001BR0000508467743993",
  "payoutAmount": "100.00",
  "payoutType": "CPF",
  "payoutStatus": "REFUND",
  "serviceAmount": "1.00",
  "completeTime": "2026-09-17 15:30:00",
  "refundNo": "REFUND202609170001",
  "refundAmount": "100.00",
  "refundTime": "2026-09-17 16:00:00"
}
```

## 响应参数

| 字段 | 类型 | 必填 | 示例值 | 说明 |
|---|---|---|---|---|
| `result` | String | 是 | `SUCCESS` | 返回 `SUCCESS` 表示已成功接收；其他值按失败处理 |
| `msg` | String | 否 | `OK` | 处理结果说明 |

## 响应示例

```json
{
  "result": "SUCCESS",
  "msg": "OK"
}
```



<div class="country-note">只有巴西代付回调包含退款相关字段；其他国家不会返回 <code>refundNo</code>、<code>refundAmount</code> 或 <code>refundTime</code>。</div>
